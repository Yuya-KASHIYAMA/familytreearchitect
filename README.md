FamilyTreeArchitect (Ver.5.0)

このHTMLは、家系図を構築する目的のWebアプリとして github.com/Yuya-KASHIYAMA により制作された。
ローカルまたはvercel (https://familytreearchitect.vercel.app/) からアクセス可能。

使い方: このHTMLファイルと付随するJSONファイルでオリジナルの家系図を作成・保存・読み込み・編集・閲覧することが可能。
初期画面の「You(あなた)」をクリックし編集することで作成を開始。
右上のメニューから作成した家系図をJSONファイルで保存したり、既存の家系図のJSONファイルをインポートし読み込みしたりすることができ、PNG出力ボタンで家系図を画像として書き出せる。
左上のメニューから言語(JP / mix / EN)を切り替えられる。

ご意見・バグ報告は制作者まで。
