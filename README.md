名称: FamilyTreeArchitect (Ver.2.9)

このHTMLは家系図を構築する目的のWebアプリとして github.com/Yuya-KASHIYAMA により制作された。

index.html をダウンロードし、ローカル環境で開くだけで動作する。(PCを想定。)

また、vercelにログイン状態で https://familytreearchitect.vercel.app/ からもアクセス可能。

使い方: このHTMLファイルと付随するJSONファイルでオリジナルの家系図を作成・保存・読み込み・編集・閲覧することが可能。
初期画面の「Self(自分)」をクリックすることで作成を開始。
右上のメニューから作成した家系図をJSONファイルに保存したり、既存の家系図のをインポートし読み込むことができる。
左上のメニューから言語(日本語・英語・混在)を切り替えられ、混在モードでは場所/Locationに「日本」または「Japan」を含むものだけ日本語表示、その他は英語表示が優先される。

お願い: 不具合を発見した場合、改善点を提案したい場合は制作者に是非報告を。

次期アップデート予定: 完全英語対応、姓・ミドルネーム・旧姓など個別の表示・非表示モード、配置整理モード、など…
